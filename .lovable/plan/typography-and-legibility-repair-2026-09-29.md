# Typography and Legibility Repair

## Goal
Make every line readable and prevent collisions across the complete portfolio on desktop, tablet, and mobile.

## Changes
- Replace compressed line heights and uncontrolled oversized type with stable, section-specific size ranges.
- Give long film titles, labels, credentials, navigation, location text, and the email address enough wrapping room.
- Rebalance grids and spacing so rules divide sections cleanly without crossing text.
- Simplify the outlined headline where needed while preserving the Field Standard industrial identity.
- Add focused tablet and small-mobile layouts for the masthead, project metadata, studio details, and footer.
- Verify the full page visually at desktop, tablet, and mobile sizes, including overflow and overlap checks.

## Technical details
- Keep the current content, exact logo, Satoshi, palette, YouTube embeds, and section order unchanged.
- Limit changes to presentation styles and accessibility-safe text flow.
